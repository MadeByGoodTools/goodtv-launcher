# Bundled video media

The published APK includes 18 Snoopy video clips in this collection. The MP4
files are kept outside source control and copied here when packaging the release.
The launcher also builds without these files; the collection then stays hidden.

These third-party media assets are separate from the launcher's GPL-licensed
source code. The software license does not grant rights to the characters,
trademarks, or video footage. Redistribution permission must be obtained separately.
